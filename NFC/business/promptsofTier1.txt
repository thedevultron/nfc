2. THE MOTION SYSTEM (Apple-grade, non-negotiable)
────────────────────────────────────
Create /src/config/motion.config.ts as the single source of truth for ALL animation physics:

export const motionConfig = {
  springs: {
    snappy:   { type: "spring", stiffness: 500, damping: 32, mass: 0.9 },  // buttons, taps
    smooth:   { type: "spring", stiffness: 300, damping: 30, mass: 1 },     // card entrances
    elastic:  { type: "spring", stiffness: 420, damping: 18, mass: 1 },     // star rating pop
    drawer:   { type: "spring", stiffness: 380, damping: 38 },              // bottom sheets
  },
  stagger: { children: 0.045, delayChildren: 0.08 },
  press: { scale: 0.96, brightness: 0.94 },
  hover: { scale: 1.02 },
  haptics: {
    tap: 8,
    selection: 12,
    success: [10, 40, 10],
    error: [20, 30, 20, 30],
  },
};

Behavior rules to implement everywhere:
- EVERY tappable element uses `whileTap={{ scale: motionConfig.press.scale }}` + haptics.service call on `onTapStart`.
- Page/mode transitions use `AnimatePresence mode="wait"` with a 20px vertical slide + opacity fade (never a hard cut).
- Lists (social hub links, feature buttons) stagger in using `staggerChildren` from motion.config — never all elements fading in at once.
- Bottom drawers (Feedback, vCard, WiFi) use REAL drag-to-dismiss gesture via Framer Motion `drag="y"`, `dragConstraints`, and velocity-based `onDragEnd` snap logic — exactly like iOS sheets. Include a rubber-band overscroll resistance.
- Star rating: each star does an elastic overshoot pop (`scale: [1, 1.35, 1]`) on select, cascades a tiny 40ms delay per adjacent star for a "ripple" feel.
- Success/error states use a spring-in checkmark/x icon (Lucide `CheckCircle2` / `XCircle`) with a circular progress-ring wipe, not a plain toast.
- Respect `useReducedMotion()` — swap springs for simple 150ms ease-out fades when true.
- No animation exceeds 500ms total perceived duration. Nothing should ever feel like it's "waiting" on animation.

3. VISUAL DESIGN SYSTEM
────────────────────────────────────
- NO logo images/PNGs — 100% Lucide React icons for all branding marks, badges, and empty states.
- Typography: Geist or Inter Variable, tight tracking (-0.01em to -0.02em) on headings, tabular-nums for any numeric ratings/counters.
- Dark-first design (`defaultMode: "dark"`), true black-adjacent background (`hsl(224 71.4% 4.1%)`), never pure #000.
- Glassmorphism panels: `backdrop-blur-xl bg-background/70 border border-white/10 shadow-[0_8px_30px_rgba(0,0,0,0.35)]`.
- Radius scale from theme.config (default 0.75rem), consistently applied — cards, buttons, drawers all share the same radius token, never mismatched.
- Safe-area padding (`env(safe-area-inset-bottom)`) on all fixed bottom elements (CTA bar, drawers).
- Every primary CTA has a soft ambient glow using the accent color at 20% opacity blurred behind it (`shadow-[0_0_40px_var(--accent)/0.25]`) — this is the "premium" tell.
- Skeleton loading shimmer (Shadcn Skeleton + custom gradient sweep animation) for the first 200-400ms while config loads — app must NEVER show a blank white/black flash.

────────────────────────────────────
4. TOUCHPOINT MODULES (render conditionally via client.config.activeMode)
────────────────────────────────────
MODULE A — Smart Review Router (REVIEW)
- 5 interactive Lucide `Star` icons, elastic pop + haptic `selection` on tap.
- Rating ≥ 4: Reveal (spring, staggered) a high-contrast CTA "Post on Google Maps" with `ExternalLink` icon → opens googleReviewUrl. Confetti-lite micro burst (6-8 particles, Lucide Sparkle icons, physics-based fall) on tap for delight.
- Rating < 4: Smoothly morph star card into a bottom Drawer ("Tell us what went wrong — this goes straight to the owner, not public"). Textarea + submit button. On submit: optimistic success state (spring checkmark) THEN POST to n8nFeedbackWebhook via api.service. Payload: { rating, feedbackText, timestamp, touchpointId }.

MODULE B — Instant WiFi Touchpoint (WIFI)
- Glass card showing SSID + masked password with an eye-toggle reveal.
- "Copy Password" button → clipboard API + haptic success pattern + inline checkmark morph (no toast spam).
- Optional native WiFi QR payload generator button.

MODULE C — Dynamic Contact / vCard (CONTACT)
- Large "Save Contact" primary CTA (Lucide `UserPlus`) generating a downloadable .vcf blob client-side.
- Secondary row: WhatsApp (`MessageCircle`) and Call (`Phone`) buttons, staggered in, each with distinct brand-tint glow.

MODULE D — Multi-Link Social Hub (HUB)
- Vertically staggered list of pill/card buttons pulled from touchpoints.config (label, icon, url, external boolean).
- Each row: icon in a soft-tinted rounded square, label, chevron-right (`ChevronRight`) that nudges 2px on hover/press.
